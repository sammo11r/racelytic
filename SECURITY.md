# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Email `racelytic@gmail.com` with:

- the affected page, route or component;
- steps to reproduce the issue;
- the likely impact;
- any suggested mitigation;
- a safe way to contact you for follow-up.

Avoid accessing data that does not belong to you, disrupting the service or
publishing exploit details before the issue has been assessed.

You should receive an acknowledgement within seven days. Confirmed issues will
be prioritised according to impact, and disclosure timing will be coordinated
with the reporter where practical.

## Supported version

Security fixes are applied to the current `main` branch and the production
deployment. Older commits and private local modifications are not supported.
