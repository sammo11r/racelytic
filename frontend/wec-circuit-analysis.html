Data & methodology

Each car contributes one race result. Class wins and podiums follow the official class classification; all crew members receive that entry result. DNS and withdrawn entries are excluded from starts. Completion compares laps completed with the leading lap total in the same class and event. Changing class names are preserved rather than merged across eras.
